# Сборка проекта

Убей все node-процессы и запусти production-сборку.

## Шаги

1. Убей все node-процессы:
   ```bash
   taskkill //f //im node.exe
   ```
   Если процессов нет — это нормально, продолжай.

2. Убедись что используется Node.js 22 (не 24):
   ```bash
   node --version
   ```
   Если версия 24.x — переключи: `nvm use 22.22.1`

3. Запусти сборку:
   ```bash
   cd c:/laragon/www/materionextjs_1/typescript-version/full-version && pnpm build
   ```

4. Если сборка завершилась с ошибками:
   - Покажи список ошибок
   - Предложи исправления
   - Спроси пользователя, хочет ли он чтобы ты исправил их автоматически

5. Если сборка успешна — выведи:
   - Время сборки
   - Количество страниц/routes
   - Размер бандла (если доступен)
   - Предупреждения (если есть)
