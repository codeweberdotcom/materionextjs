# План (Roadmap): Отвязка OAuth-аккаунта (Яндекс и др.)

**Дата создания:** 2026-03-16
**Статус:** Отложено
**Приоритет:** Средний

---

## 🎯 Цель

Дать пользователю возможность отвязать OAuth-провайдер (Яндекс, Google и др.) из настроек профиля, при условии что установлен пароль для входа через email.

## 📊 Этапы реализации

### Этап 1: API — установка пароля для OAuth-пользователей

**Задачи:**
- [ ] `PUT /api/user/set-password` — установить пароль (только если `user.password === null`)
- [ ] Валидация: минимум 8 символов, подтверждение пароля
- [ ] Event: `user.password_set`

### Этап 2: API — отвязка OAuth-провайдера

**Задачи:**
- [ ] `DELETE /api/user/oauth/[provider]` — удалить `Account(provider, userId)`
- [ ] Guard: запрещать если `user.password === null` (нет другого способа войти)
- [ ] Guard: запрещать удаление последней OAuth-записи если нет пароля
- [ ] Event: `user.oauth_unlinked`

### Этап 3: UI — секция в настройках профиля

**Задачи:**
- [ ] Показать список привязанных OAuth-провайдеров
- [ ] Кнопка "Отвязать" (disabled если нет пароля, с подсказкой)
- [ ] Форма "Установить пароль" для OAuth-пользователей
- [ ] i18n: 4 словаря

---

## ⚠️ Бизнес-правила

- Нельзя отвязать провайдера, если `password === null` — пользователь заблокирует себя
- После отвязки пользователь входит по email + пароль как обычно
- Можно иметь несколько OAuth-провайдеров одновременно (Яндекс + Google и т.д.)
