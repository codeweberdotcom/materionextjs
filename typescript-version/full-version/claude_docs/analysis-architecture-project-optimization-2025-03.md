2025-03-12

## Область анализа
- Архитектура

## Проблемы

1. **Дублирование boilerplate в ~129 API routes**
   - Описание: Каждый route handler содержит дублированный код авторизации, обработки ошибок, проверки прав и форматирования ответов
   - Влияние: Высокое — ~3000 строк дублированного кода, высокий риск несогласованности
   - Приоритет: Высокий

2. **Небезопасные catch-блоки (`catch (error: any)`)**
   - Описание: 17+ файлов используют `catch (error: any)` вместо `catch (error: unknown)` с проверкой `instanceof Error`
   - Влияние: Среднее — нарушение TypeScript best practices
   - Приоритет: Средний

3. **Отсутствие DB индексов на foreign keys**
   - Описание: 15 индексов отсутствуют на часто используемых FK и composite полях
   - Влияние: Высокое — деградация производительности при росте данных
   - Приоритет: Высокий

4. **Синхронная загрузка тяжёлых компонентов**
   - Описание: FullCalendar (~1.2MB) и react-map-gl (~600KB) загружаются синхронно
   - Влияние: Среднее — увеличение initial bundle на ~1.8MB
   - Приоритет: Средний

5. **Дублирование библиотек валидации (Valibot + Zod)**
   - Описание: 6 файлов используют Valibot, остальные — Zod
   - Влияние: Низкое — лишний bundle size
   - Приоритет: Низкий

6. **`requireAuth()` не возвращает обогащённые данные**
   - Описание: Каждый route дополнительно вызывает `prisma.user.findUnique` для роли и email
   - Влияние: Среднее — дублирование запросов к БД
   - Приоритет: Средний

## Рекомендации

1. Создать `withApiHandler()` wrapper — Сложность: Высокая
2. Исправить catch-блоки на `error: unknown` — Сложность: Низкая
3. Добавить 15 индексов в Prisma schemas — Сложность: Низкая
4. Dynamic imports для тяжёлых компонентов — Сложность: Низкая
5. Унификация на Zod, удаление Valibot — Сложность: Низкая
6. Расширить `requireAuth()` для enriched user — Сложность: Средняя
